# Launch screen assets

The launch screen uses `AmperfyKit/Assets/Assets.xcassets/LaunchBackground.imageset/LaunchBackground.svg` as a full-bleed vector gradient and `AmperfyKit/Assets/Assets.xcassets/LaunchNote.imageset/LaunchNote.png` as its centered, transparent foreground.

The foreground was extracted with the built-in image generation tool from the existing `Icon-1024` asset. The app icon itself was not changed.
