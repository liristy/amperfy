# Apple Music 录屏动作参考（2026-11-12）

依据用户提供的 30.8167 秒录屏，画面为 1320 × 2868，约 60 fps。
逐帧测量记录保存在本地 `build/apple-music-reference-2026-11-12/`；原视频和图片不提交到仓库。
几何按录屏的 3 倍屏幕倍率换算。以下数值来自实际画面，不把现有实现的参数当作参考。

| 动作 | 录屏时间 | 观察与测量 |
| --- | --- | --- |
| 进度条按住 | 13.86–14.42 s | 厚度 21→51 px（7→17 pt），宽度 1128→1184 px（约 1.05 倍），中心不变，端部保持圆形；时间文字与已播放部分变亮，时间文字向两边跟随展开。 |
| 进度条松手 | 15.16–15.70 s | 高度先降到约 18 px，再回到 21 px；不是单调线性缩小。宽度同步有轻微回弹。 |
| 第二次拖动 | 16.00–17.70 s | 重复同一几何和节奏；开始按压时显示当前进度，拖动后才改变预览值。 |
| 音量拖动 | 17.89–18.95 s、19.45–20.85 s | 同样约 7→17 pt、横向 1.05 倍；两边扬声器向外移动并变亮，落指没有可见的音量跳转。 |
| 下一首 | 9.00–9.32 s、24.9–27.4 s | 前三角形原地缩小淡出，后三角形移到前方，新三角形从后方长出。中间短暂存在三层，不能用整枚图标平移代替。 |
| 播放/暂停图标 | 0.94–1.30 s、23.9–24.3 s | 原图标缩小淡出时，新图标已开始出现；两者短暂重叠，不先清空画布再换图。 |
| 暂停封面 | 23.94–24.64 s | 宽度约 1176→858 px，缩到约 73%，平顺收拢。 |
| 恢复封面 | 1.02–1.65 s | 从约 73% 放大，峰值约 103.2%，随后回到 100%；与暂停采用不同曲线。 |

轨道宽度的弹簧拟合：按压阻尼比约 0.75、固有角频率约 16.6；释放阻尼比约 0.63、固有角频率约 15.7。拟合宽度的均方根误差约 0.53 px。实现用一套几何动画同时改变轨道宽、高和圆角，不拉伸圆角位图。轨道填充比例保持在当前几何内，避免展开时数值边界错位。

录屏没有手指触点标记，不能直接读取落指位置。相对拖动是根据按压初期进度保持不变、随后才改变的表现以及现有音量交互作出的实现选择。保留指针点击定位和原生无障碍调节；触屏轻点不提交 seek，实际拖动在松手时只提交一次，取消不提交。

这段参考没有展示播放器展开/收起，也没有单独触发上一首。展开/收起沿用现有实现；上一首采用下一首动作的镜像。不要宣称未出现在视频中的动作已经逐帧比对。

回归要求：测量实际呈现层的厚度、宽度和回弹；验证单次提交、取消、禁用、移出窗口和快速反向；用合成器截图确认轨道像素。播放/暂停、前后切歌和封面需要核对实际录屏，`drawHierarchy` 的静态图不能单独证明动画已经渲染。

检查完整播放器时还要确认展开后的两端圆角和时间文字完整可见。控件容器不能按静止轨道的左右边界裁切；仅在沉浸歌词收起控件时启用裁切。孤立轨道的厚度测试无法发现这类父视图裁切问题。
