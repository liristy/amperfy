# 播放器布局约定

歌词保留常驻的顶部信息视图；播放列表中的当前曲目卡片属于队列滚动内容。两处信息均包含封面、歌名、歌手、收藏和更多按钮。

- 歌词顶部信息视图挂在全屏播放器根视图上，不属于歌词滚动区。队列当前曲目卡片随歌曲和播放模式滚动，底部控制区保持固定。
- 顶部与播放器内容区对齐，高度 94 pt，左右内缩 8 pt；封面为 72 × 72 pt，完整适配原图比例。
- 两页使用相同的文字位置、字号、颜色、可用宽度和按钮位置。不得另建一套列表标题布局。
- 歌词与列表切换时协调封面与信息区的位置和可见性，快速反向切换后恢复当前页面布局，避免同时显示两张封面。
- 同步歌词仅当前行清晰，已唱过和未唱到的行使用 1.8 pt 高斯模糊与半透明文字，切换高亮时平滑过渡。无时间戳歌词保持可读；模糊图像按文字、尺寸和屏幕倍率缓存，不在播放计时回调中反复渲染。
- 隐藏或恢复歌词控制区不改变歌词顶部信息的位置。队列标题直接位于滚动内容的区段位置，不使用悬浮标题覆盖歌曲；空历史和空手动队列不保留标题空间。
- 进入或退出大封面模式执行封面缩放过渡；暂停时仅大封面与阴影缩到 74%（录屏中的暂停比例），播放时平滑恢复原尺寸，暂停和播放均不使用封面弹簧。歌词与队列的小封面不随播放状态缩放。横竖屏转换可随整体布局调整固定区域。
- 顶部三点菜单统一包含歌曲操作与播放器选项，底部控制区不再提供重复三点入口。
- 全屏播放器按钮默认使用白色无底框图标；歌词、队列、收藏等选中态使用白色图标与圆形半透明白底（16%），不使用橙色主题高亮或方形底。播放、上一首、下一首不添加底框。
- 底部歌词、AirPlay、播放列表图标统一使用 24 pt，保留 44 × 44 pt 点击区域；刷新播放状态或切换页面时保持该尺寸。
- 中间输出按钮独立监听音频路由与应用恢复，合并切换期间的短暂输出状态，播放/暂停和歌曲信息刷新不得重置图标。AirPods 3/4 使用短柄图标；未注明代数的 AirPods 名称默认采用这一外观，明确的 AirPods 1/2、Pro、Max 保留各自外观。名称不能可靠识别硬件代数，长按可选择并按端口 UID 记忆外观；点按仍打开系统输出选择器。同一 UID 临时变成通用蓝牙名称时沿用已知外观，确认切换到手机或其他设备后更新；不得通过私有 API 推断型号。
- iPhone 使用系统原生底部导航，入口为首页、资料库、聆听统计和搜索；迷你播放条通过 `UITabAccessory` 挂载，玻璃与收起行为交给系统处理。
- 点按或上拉展开全屏播放器，整个播放器面板从播放条胶囊的坐标与尺寸弹性展开；收起时整页缩回同一播放条并回弹。背景、文字和控制区以 0.78 秒、0.62 阻尼的弹簧共同缩放与位移，回弹必须在真实内容上可见。专辑封面同时从播放条封面的位置连续移动、放大到当前页面封面（包括暂停缩小后的封面、歌词和队列顶部封面），收起时沿原路返回；封面与整页共用手势进度，但封面通过独立逐帧渲染按缓入缓出曲线完成或取消，不进入系统转场的弹簧动画组，不能越过终点或往返回弹；整页缩放行程从 72% 到 100%，下移行程为页面高度的 12%，回弹时真实内容缩放需超过 1.2%。转场中仅显示一张移动封面，结束或取消后恢复两端封面及阴影、移除临时图层。减少动态效果时保留淡入淡出，不执行封面飞行。

模拟器回归检查覆盖双向切换、快速反向切换、队列历史滚动、空区段标题和歌词控制区隐藏/恢复，并检查封面与控件的坐标、尺寸及可见性。

全屏转场直接裁切真实播放器并做弹性缩放，不先显示整页截图再替换真实视图；结束与取消时恢复遮罩、透明度和变换。背景加载前使用缓存封面配色或中性深灰，禁止闪过主题橙色；新配色平滑过渡，重复打开复用配色缓存。

转场中的真实封面和阴影使用独立透明遮罩隐藏，不得依赖会被刷新回调改写的 alpha。播放器表面在展开与收起的主要行程中持续不透明，只在胶囊端点的 3.5% 进度内交接透明度，不能用整页淡入淡出遮住胶囊变形和回弹。前景在展开 5%–35% 进度内出现，在收起 35%–65% 进度内隐藏，防止全屏控件进入胶囊。播放条保持真实可见；禁止缓存离屏玻璃截图作为播放条替身。结束及中途反转均恢复原遮罩。回归必须检查实际渲染层的透明度，覆盖展开早段、整页回弹、暂停、深色模式、刷新与收起末段，不能只检查模型层 alpha。

导航回归检查实际系统标签与播放附件，覆盖页面切换、搜索键盘、播放页退出后的选中标签和聆听统计浏览位置恢复。

播放器常规页按用户 Apple Music 录屏调整比例：20 pt 歌名与歌手构成两行信息，专辑操作保留在菜单；封面 8 pt 圆角，控制区与文字比封面内缩 8 pt。进度轨道静止时 7 pt、拖动时 11 pt，音量轨道按下时按相同比例变粗。控制区高度 268 pt，上一首/下一首使用 26 pt 常规字重，底部三按钮仍保留 24 pt 图标与 44 pt 点击区域。背景从封面取色后混合中性灰，避免高饱和色与近黑大斑块。转场前景随面板上移，独立封面只沿端点之间平滑运动。

歌词区域向下滑动恢复播放控制，向上滑动隐藏控制进入全屏歌词；歌词滚动手势优先于整页关闭手势，即使位于第一行也不能下滑误关播放器。播放列表中的随机、循环、自动续播采用独立原生玻璃胶囊，材质放在表格合成层之外；歌曲行高 56 pt，封面 44 pt，显示歌名/歌手及拖动排序标记。自动续播单独显示推荐区段，不允许拖动排序，手动添加的队列优先。Apple Music 的混音/翻译/人声功能未接入当前音频引擎，不放置无效仿制开关。

全屏音量条使用原生系统音量，通过透明触摸层接收相对水平拖动；点按不跳到绝对音量位置。原生音量轨道重新布局后重新校正中心，按压动画只改变外层的纵向比例，不改原生滑块几何和横向触摸坐标。两侧图标为亮度一致的非交互指示，大封面不承担打开队列操作。
