# 聆听统计

底部导航依次为首页、资料库、聆听统计和搜索，四项使用同一个系统原生导航栏。

首次打开聆听统计，点击「连接 Maloja」，填写本地 Feishin 聆听统计中使用的 Maloja 地址。地址按当前音乐账户保存，可随时通过右上角设置修改或清空。手机必须能访问该地址；桌面上的 localhost 地址在手机上指向手机自身。

统计读取 Maloja 的历史数据，不会重新上传、补写或复制已有听歌记录。音乐播放和 scrobble 提交继续使用现有音乐服务器设置，音乐服务器的认证信息不会附加到 Maloja 请求。

功能包括：

- 总览：聆听次数、歌手／专辑／歌曲数量、趋势、热门排行与最近记录。
- 排行：歌手、专辑和歌曲分类、搜索、翻页与详情。
- 趋势：日／周／月／年间隔、累计统计、滚动窗口与数据表。
- 分时榜单：各时间段的榜首，支持切换类别和间隔。
- 聆听历史：按日期分组、时间、时长、来源和翻页。
- 详情：历来次数、名次、榜首周数、认证、奖牌、关联歌手、趋势及历史。
- 播放：歌曲按名称和歌手匹配当前资料库，同名歌曲优先匹配原专辑。未找到时给出提示。

日期筛选支持今天、本周、本月、今年、全部时间和自定范围。认证、奖牌和历来排名是全时期信息，其余内容遵循选择的日期范围。

封面优先使用已同步资料库的图片，缺失时尝试 Maloja。统计图表和操作按钮跟随账户主题色，导航和操作控件采用苹果原生液态玻璃。

GitHub 回归使用本地测试服务器验证真实 HTTP 请求、Maloja 响应解析、日期及实体参数、翻页、空数据、HTTP 错误和歌曲播放，不访问用户的真实历史。
