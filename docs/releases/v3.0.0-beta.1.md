# qMusic 3.0 Beta 1

qMusic 首个 3.0 预发行版，基于 Amperfy，面向 Navidrome / Subsonic / Ampache 音乐服务器。

## 本版变化

- 重新设计全屏播放器、歌词与迷你播放条，支持封面缩放、下滑退出及非正方形封面的完整显示。
- 歌词与播放队列共用固定的封面和标题区，互切、滚动和隐藏控制区时保持位置不变。
- 迷你播放条左右拖动连续展示相邻曲目，支持中途退回取消。
- 改用五角星收藏，默认橙色主题，提供简体中文与英语。
- 默认资料库显示艺人、专辑、歌曲、收藏、歌单和下载，歌单使用 Navidrome 提供的封面。
- 增加“定时停止播放”和“随机播放收藏”快捷指令动作。
- 修复自动切歌信息更新、歌词高亮、锁屏播放恢复、延迟加载封面的锁屏更新及听歌记录提交问题。
- 移除评分与转码设置，应用显示名称改为 qMusic。

## 下载与安装

下载附件 **qMusic-3.0.0-beta.1.ipa**，使用爱思助手及自己的 Apple ID 签名后安装。要求 **iOS 26 或更新版本、arm64 iPhone / iPad**。App 内版本号为 **3.0.0（1）**。

此前侧载版本用户请保持原 Apple ID 和应用标识，直接覆盖安装。包内已预建 Apple ad-hoc 签名结构，但仍需要个人签名；它不包含 Siri / CarPlay 的专用授权。Apple ID 和密码无需上传到 GitHub。

附件提供安装说明、SHA-256 校验、构建来源、IPA 检查脚本及打包完整性记录。ListenBrainz 等下游听歌记录服务需要在 Navidrome 服务端配置。

## 验证范围

发布工作流必须通过 173 项回归测试、iPhone 模拟器登录与播放器交互检查、固定标题区逐帧检查，以及 IPA 框架完整性校验才会发布。模拟器与文件验证不代表所有真机、服务器或个人签名环境均已验证。
