# qMusic for iOS 3.0 Beta 2

本版加入 Maloja 聆听统计，并集中修复播放器液态玻璃、队列显示、音量交互与播放动画，完善自动续播和后台资源管理。

## 本版变化

- 修复队列标题、历史歌曲与当前曲目信息重叠，以及反复打开播放器后的玻璃材质显示异常；队列标题与曲目随列表自然滚动。
- 播放／暂停采用居中缩小、切换图标、恢复的动效，修复图标变形、跳动及连续点击后的状态错误；上一首／下一首增加切歌反馈。
- 音量条使用系统音量，按住后左右相对滑动调节；加入与进度条一致的按下变粗、松手恢复动效，修复首次打开时上浮和图标对齐问题。两侧音量图标亮度一致，点击不再弹出额外音量条。
- 移除大封面点击打开队列的操作，保留底部播放列表入口。
- 关闭循环和自动续播时，最后一首点击下一首或播放结束会暂停并保留当前歌曲、封面与进度；修复加载歌曲期间点击暂停后又自动播放的问题。
- **∞ 自动续播**会提前准备独立的推荐队列，优先使用服务器相似曲目，再从当前账号资料库补充；手动添加的歌曲优先播放，支持关闭推荐和离线缓存曲目。推荐取决于服务器与个人资料库。
- 后台播放暂停歌词与频谱的界面刷新，保留音频、锁屏信息、预加载和听歌记录更新；回到前台恢复显示。
- 新增 Maloja 聆听统计，支持总览、排行、趋势、历史、歌曲详情及匹配资料库播放；按音乐账号保存连接地址，返回统计页时保留浏览位置。
- 统一原生底部导航与搜索，优化播放器展开／收起、迷你播放条及输出设备图标。

## 下载与安装

下载附件 **qMusic-3.0.0-beta.2.ipa**，在爱思助手中使用自己的 Apple ID 签名后安装。要求 **iOS 26 或更新版本、arm64 iPhone / iPad**，App 内版本为 **3.0.0（2）**。

从 Beta 1 或此前侧载版本更新时，保持原 Apple ID 和应用标识，直接覆盖安装以保留资料库与下载。包内预建 Apple ad-hoc 签名结构，安装前仍需个人签名；发布包不包含 Siri / CarPlay 的专用授权。完整步骤见随包的 `iphone-install-zh.md`。

附件同时提供 `SHA256SUMS`、`build-info.txt`、`ipa-integrity.log` 和 `verify_ipa.py`，用于核对文件完整性与构建来源。

## 验证范围

发布工作流通过 184 项资料库与播放回归、完整 iPhone 模拟器界面检查、Release 真机包构建及 IPA 完整性校验后发布。界面检查覆盖队列、歌词、原生玻璃、音量相对拖动与布局、快速播放／暂停、自动续播及聆听统计。

模拟器检查不替代真机动画手感、系统音量同步与不同服务器的实际验证。后台资源优化已经过模拟器 CPU／内存采样，尚无真机电池耗电量测量结果。
